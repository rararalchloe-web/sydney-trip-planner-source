# 시드니 취향 여행 플래너

연령대, 여행 스타일, 동행 유형을 고르면 시드니 5일 여행 동선과 맛집, 쇼핑, 옷차림을 추천하는 웹앱입니다.

## 사용 방법

1. 화면 위쪽에서 연령대, 여행 스타일, 누구와 여행하는지 선택합니다.
2. `결과 보기`를 눌러 추천 동선과 여행 정보를 확인합니다.
3. 각 공식 사이트 링크에서 운영 시간과 예약 정보를 확인합니다.

선택한 조건으로 브라우저에서 추천 내용을 계산합니다. 이름, 전화번호, 주소 등 개인 정보를 입력받거나 서버에 저장하는 기능은 없습니다.

## 내 컴퓨터에서 미리 보기

Node.js 22 이상과 pnpm이 필요합니다. 처음 한 번 `pnpm install`로 준비하고, `pnpm dev`를 실행한 다음 터미널에 표시된 주소를 브라우저에서 여세요.

## GitHub Pages에 공개하기

저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택하세요. 이후 `main` 브랜치에 올리면 GitHub Actions가 사이트를 빌드해 공개합니다.
